# FE Fixes PR1 (quick wins) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Land three low-risk frontend fixes — "mark as read" actually clears the notification dots + bell badge, the guided tour stops breaking when the sidebar is collapsed, and the collapse/expand FAB no longer overlaps adjacent sidebar UI.

**Architecture:** All three are client-only changes in the Next.js frontend. State lives in two Zustand stores (`useAppStore`, `useTourStore`); UI is inline-styled React components. No backend, no API, no new i18n strings (all copy already exists in the dictionary).

**Tech Stack:** Next 15 App Router, React 18, Zustand 4, Vitest 4 + Testing Library + jsdom.

## Global Constraints

- All commands run from `frontend/` (the Next app root). Never from repo root.
- Test runner: `npm test -- <path>` (alias for `vitest run --passWithNoTests <path>`); single test: append `-t "<name>"`.
- Persisted store key is `snoopify_v1`; persisted fields are whitelisted in `PERSIST_KEYS` in `store/useAppStore.ts`.
- Match existing conventions: inline `style={{…}}` objects, `useAppStore((s) => s.field)` selectors, `data-*` attributes for test/anchor hooks (the repo already uses `data-tour`, `data-screen-label`).
- This PR adds **no** new i18n keys; it reuses `t.markRead` etc.
- PR1 is implemented on a dedicated branch off `main` (e.g. `fix/fe-pr1-quick-wins`).

### Task 2: Guided tour auto-expands a collapsed sidebar, restores after

The tour highlights sidebar anchors (`nav`, `add`, `decks`). When the sidebar is collapsed, `.side-decks` is `display:none`, so the `decks` step's `getBoundingClientRect()` is all-zero and the ring renders as a broken artifact at (0,0). Fix: when the tour starts, expand the sidebar (remembering its prior state); restore on end. Both entry points (the Topbar "Guide" button and the auto-start in `AppShell`) call `startTour`, and every exit path (Done/Skip/finish) calls `endTour`, so centralizing the logic in `useTourStore` covers all cases.

**Files:**
- Modify: `frontend/src/store/useTourStore.ts` (import `useAppStore`; add `priorCollapsed`; expand on start, restore on end)
- Test: create `frontend/src/store/useTourStore.test.ts`

**Interfaces:**
- Consumes: `useAppStore` state `collapsed: boolean` (read via `useAppStore.getState()`, write via `useAppStore.setState(...)`).
- Produces: `useTourStore` gains state field `priorCollapsed: boolean`. No signature change to `startTour()` / `endTour()`.

- [ ] **Step 1: Write the failing test**

Create `frontend/src/store/useTourStore.test.ts`:

```ts
import { describe, it, expect, beforeEach } from 'vitest'
import { useTourStore } from './useTourStore'
import { useAppStore, initialState } from './useAppStore'

describe('useTourStore sidebar coordination', () => {
  beforeEach(() => {
    localStorage.clear()
    useAppStore.setState({ ...initialState })
    useTourStore.setState({ tourActive: false, tourStep: 0, tourRect: null, tourGen: 0, priorCollapsed: false })
  })

  it('expands a collapsed sidebar when the tour starts', () => {
    useAppStore.setState({ collapsed: true })
    useTourStore.getState().startTour()
    expect(useAppStore.getState().collapsed).toBe(false)
    expect(useTourStore.getState().priorCollapsed).toBe(true)
  })

  it('restores the collapsed sidebar when the tour ends', () => {
    useAppStore.setState({ collapsed: true })
    useTourStore.getState().startTour()
    useTourStore.getState().endTour()
    expect(useAppStore.getState().collapsed).toBe(true)
  })

  it('leaves an already-expanded sidebar expanded through the tour', () => {
    useAppStore.setState({ collapsed: false })
    useTourStore.getState().startTour()
    useTourStore.getState().endTour()
    expect(useAppStore.getState().collapsed).toBe(false)
  })
})
```

```ts
  startTour: () => {
    const priorCollapsed = useAppStore.getState().collapsed
    if (priorCollapsed) useAppStore.setState({ collapsed: false })
    try { window.scrollTo({ top: 0, behavior: 'smooth' }) } catch { /* ignore */ }
    set((s) => ({ tourActive: true, tourStep: 0, tourRect: null, tourGen: s.tourGen + 1, priorCollapsed }))
    const gen = get().tourGen
    setTimeout(() => {
      if (get().tourGen !== gen || !get().tourActive) return
      get().goTour(0)
    }, 180)
  },
```

replace the existing `endTour` with one that restores prior state:

```ts
  endTour: () => {
    try {
      localStorage.setItem('myenglish_tour_done', '1')
    } catch { /* ignore */ }
    if (get().priorCollapsed) useAppStore.setState({ collapsed: true })
    set((s) => ({ tourActive: false, tourStep: 0, tourRect: null, tourGen: s.tourGen + 1, priorCollapsed: false }))
  },
```
